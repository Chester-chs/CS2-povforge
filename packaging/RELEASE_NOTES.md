## PovForge v0.16.1

Download **PovForge-Setup.exe** to install or update; **PovForge-windows.zip** is the portable edition.

### English

- Increase contrast for small helper text, counts, weapon details and video metadata in light and dark themes, including following the system theme.
- Slightly enlarge helper text and make search placeholders easier to read while retaining the current layout and visual hierarchy.

### 简体中文

下载安装或更新请使用 **PovForge-Setup.exe**；免安装版使用 **PovForge-windows.zip**。

- 提高说明文字、数量标签、武器详情和成片信息的对比度，覆盖浅色、深色及跟随系统主题。
- 略微增大提示文字，让搜索框占位文字更清楚，同时保留现有布局和视觉层次。

Development and testing did not launch CS2 or change the owner's game settings.
开发和验证未启动 CS2，未修改用户游戏设置。
