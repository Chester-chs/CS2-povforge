## PovForge v0.15.5

Download **PovForge-Setup.exe** to install or update; **PovForge-windows.zip** is the portable edition.

### English

- Show the actual CS2 map scenery beside the match title instead of a radar/minimap, keeping the rounded thumbnail style.
- Cache map pictures locally after the first download. Missing pictures do not block match selection or recording; switching to a supported map restores its picture.
- Retain the native Windows titlebar fix from v0.15.3 for matching light and dark backgrounds. Systems without the required WebView2/.NET runtime use the existing browser fallback.

### 简体中文

下载安装或更新请使用 **PovForge-Setup.exe**；免安装版使用 **PovForge-windows.zip**。

- 比赛标题旁改为 CS2 地图实际场景图，保留圆角样式。
- 图片首次下载后保存在本地；图片暂不可用时，不影响选择比赛或录制，切换到支持的地图后恢复显示。
- 保留 v0.15.3 的原生标题栏修复，浅色与深色背景保持一致；缺少所需 WebView2/.NET 环境时仍使用浏览器回退模式。

No CS2 launch or changes to the owner's game settings were made while developing this update.
开发此更新时未启动 CS2，也未修改用户的游戏设置。
