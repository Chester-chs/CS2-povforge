## PovForge v0.16.2

Download **PovForge-Setup.exe** to install or update; **PovForge-windows.zip** is the portable edition.

### English

- Use black text throughout light mode and white text throughout dark mode, including settings, video library, recordings, dialogs and placeholders. Following the system theme uses the same rules.
- Retain rounded surfaces and colored icons. Font size, weight and spacing distinguish text hierarchy; disabled labels stay readable and use outlines to show their state.
- Adjust dark accent-filled controls so white button text stays readable with all eight accent choices.

### 简体中文

下载安装或更新请使用 **PovForge-Setup.exe**；免安装版使用 **PovForge-windows.zip**。

- 浅色模式统一黑字，深色模式统一白字，覆盖设置、成片库、录制页面、弹窗与输入提示；跟随系统主题时一致生效。
- 保留圆角卡片和图标配色，通过字号、字重与间距区分文字层级。禁用按钮的文字保持清晰，用边框提示状态。
- 调整深色模式的强调色按钮背景，确保八种强调色下的白色文字均清楚可读。

Development and testing did not launch CS2 or change the owner's game settings.
开发和验证未启动 CS2，未修改用户游戏设置。
